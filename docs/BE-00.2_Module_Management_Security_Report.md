## API mới / thay đổi

### OWNER — quản lý module tổ chức mình

| Method | Endpoint | Permission | Mô tả |
|---|---|---|---|
| `GET` | `/api/v1/organizations/my/modules` | `ROLE_OWNER` | Danh sách module + trạng thái (is_locked_by_admin) |
| `PATCH` | `/api/v1/organizations/my/modules/{moduleCode}` | `ROLE_OWNER` | Bật/tắt Optional module |

**Request PATCH:**
```json
{ "enabled": true }
```

**Lỗi có thể gặp:**
- `1127 MODULE_IS_CORE` — tắt module lõi
- `1128 MODULE_LOCKED_BY_ADMIN` — module đang bị SA khóa
- `1132 MODULE_ALREADY_IN_STATE` — đã ở trạng thái yêu cầu
- `1109 ORGANIZATION_NOT_FOUND`, `1110 ORGANIZATION_INACTIVE`

### SUPER_ADMIN — khóa/mở khóa module

| Method | Endpoint | Permission | Mô tả |
|---|---|---|---|
| `GET` | `/api/v1/organizations/{orgId}/modules/admin` | `ROLE_SUPER_ADMIN` | Xem full state kể cả lock details |
| `PATCH` | `/api/v1/organizations/{orgId}/modules/{moduleCode}/lock` | `ROLE_SUPER_ADMIN` | Khóa/mở khóa module |

**Request PATCH:**
```json
{ "lock": true, "reason": "Policy violation — module abused" }
```

**Lỗi có thể gặp:**
- `1131 MODULE_LOCK_REASON_REQUIRED` — không có lý do
- `1127 MODULE_IS_CORE` — không khóa module lõi
- `1132 MODULE_ALREADY_IN_STATE`

### Internal — đọc trạng thái module

| Method | Endpoint | Mô tả |
|---|---|---|
| `GET` | `/internal/orgs/{orgId}/modules` | Chỉ trả code có status='active' (guard write) |
| `GET` | `/internal/orgs/{orgId}/modules/status` | Full status (active/disabled/locked) cho guard read |

## Điểm kỹ thuật cần chú ý cho Frontend

1. **`GET /api/v1/organizations/my/modules`** — Trả `is_locked_by_admin: true` khi module bị SA khóa. FE hiện thị "bị quản trị hệ thống khóa" khi field này = true.
2. **Module disabled** — API đọc vẫn trả dữ liệu (200 OK). API ghi trả `400 MODULE_NOT_ENABLED` với message chứa "read-only mode". FE nên kiểm tra message để hiện thông báo khác với "module chưa bật".
3. **Legacy codes** — `ROOM_MANAGEMENT` và `EQUIPMENT_MANAGEMENT` trong request được tự động resolve sang `FACILITY_MANAGEMENT`. FE nên dùng `FACILITY_MANAGEMENT`.
